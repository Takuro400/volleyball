# Google フォームでのエントリー受付（セットアップ手順）

エントリーは **Google フォーム → スプレッドシート → アプリ** の流れで受け付けます。
フォームの回答がスプレッドシートに入ると、Apps Script が自動でアプリに送ります。うまくいかないときは、運営画面から貼り付けて取り込めます。

## 0. 先にやること（1回だけ）

1. **Supabase**: SQL Editor で [`supabase/migrations/2026-11-form-entry.sql`](../supabase/migrations/2026-11-form-entry.sql) を実行します。
2. **Vercel**: Project → Settings → Environment Variables に次を追加して、再デプロイ（Redeploy）します。
   - Name: `IMPORT_SECRET`
   - Value: 推測されにくい長い文字列（16文字以上。例: ランダムな英数字30文字）
   - Type: **Sensitive**
   - この文字列は、後で Apps Script にも貼り付けます（他の人には見せないこと）。

## 1. フォームを2つ作る

**質問のタイトルは、下の文字どおりにしてください**（アプリがタイトルで読み取ります。後ろに説明文を足すのは自由です）。

### ① 「バレーボール大会 チームエントリー」

| 質問 | 形式 | 必須 |
| --- | --- | --- |
| チーム名 | 記述式 | はい |
| メンバー全員の名前（リーダーを1人目に、1行に1人ずつ） | 段落 | はい |

説明文の例: 「6〜8人でエントリーしてください。1人目の人がリーダーになります。」

### ② 「バレーボール大会 当日チーム分けエントリー」

1人〜3人で一緒に申し込む人用です。**同じフォームで申し込んだ人は、必ず同じチームになります。**

| 質問 | 形式 | 必須 |
| --- | --- | --- |
| 1人目の名前 | 記述式 | はい |
| 1人目の性別 | ラジオボタン（女性 / 男性 / 回答しない） | はい |
| 1人目は経験者ですか？（中学・高校でバレー部に所属） | ラジオボタン（はい / いいえ） | はい |
| 2人目の名前 | 記述式 | いいえ |
| 2人目の性別 | ラジオボタン（女性 / 男性 / 回答しない） | いいえ |
| 2人目は経験者ですか？（中学・高校でバレー部に所属） | ラジオボタン（はい / いいえ） | いいえ |
| 3人目の名前 | 記述式 | いいえ |
| 3人目の性別 | ラジオボタン（女性 / 男性 / 回答しない） | いいえ |
| 3人目は経験者ですか？（中学・高校でバレー部に所属） | ラジオボタン（はい / いいえ） | いいえ |

説明文の例: 「1人で申し込む場合は、1人目だけ入力してください。2人・3人で申し込む場合は、2人目・3人目も入力してください。」

### 質問を追加してもよい（電話番号・メールアドレス・意気込み・知ったきっかけ など）

上の表の質問に加えて、好きな質問を増やせます。追加した質問の回答は、**スプレッドシートに残るだけ**で、アプリには送られません（アプリの表示にも影響しません）。ただし、次の決まりだけ守ってください。

- 追加する質問のタイトルを、**「チーム名」「メンバー」「1人目」「2人目」「3人目」で始めない**でください（アプリが、それらの文字で始まる質問を読み取りに使います）。
  - 良い例: 「リーダーの電話番号」「意気込み」「この大会をどこで知りましたか？」「連絡先メールアドレス」
  - 避ける例: 「メンバーの人数」「チーム名のふりがな」「1人目の電話番号」→ 「代表者の人数」「ふりがな（チーム名）」「代表者の電話番号」のように言い換えます。
- 指定した質問のタイトルと選択肢は、変えないでください。
- 電話番号やメールアドレスは、スプレッドシートの閲覧権限を持つ人だけが見られます。共有の範囲に注意してください。

### 2つのフォーム共通の設定（いたずら対策）

フォームの「設定」→「回答」で次を設定します。

- **メールアドレスを収集する**（確認済み）をオン。Google アカウントでのログインが必要になり、いたずらしにくくなります。
- **回答を1回に制限**をオン。
- 「回答」タブ → スプレッドシートのアイコンで、**回答の保存先のスプレッドシートを作る**（フォームごとに別のスプレッドシート）。

## 2. 自動で反映する（Apps Script）

フォームごとに、回答のスプレッドシートで次の操作をします。

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
2. 最初からあるコードを消して、下のコードを貼り付けます。`SECRET` の文字列だけ、Vercel に設定した `IMPORT_SECRET` と同じ値に書き換えます。
3. 保存して、左の時計のアイコン「トリガー」→「トリガーを追加」。
   - 実行する関数: `onFormSubmit`
   - イベントのソース: **スプレッドシートから**
   - イベントの種類: **フォーム送信時**
4. 初回は権限の確認が出ます。自分のアカウントで許可します（「詳細」→「安全ではないページに移動」）。

```javascript
const ENDPOINT = 'https://volleyball-o74w.vercel.app/api/import/form';
const SECRET = 'ここに Vercel の IMPORT_SECRET と同じ文字列を貼り付け';
const RESULT_HEADER = 'アプリ反映';

function onFormSubmit(e) {
  const sheet = e.range.getSheet();
  const row = e.range.getRow();
  // アプリに送るのは、アプリが使う質問（チーム名・メンバー・1〜3人目）だけ。
  // 電話番号・メールアドレス・意気込みなどは、スプレッドシートの中だけに残し、アプリには送りません。
  const answers = {};
  Object.keys(e.namedValues).forEach(function (k) {
    if (/^(チーム名|メンバー|[1-3]人目)/.test(k)) {
      answers[k] = (e.namedValues[k] || [''])[0];
    }
  });
  const mail = (e.namedValues['メールアドレス'] || [''])[0];

  var status = 'error';
  var message = '';
  try {
    const res = UrlFetchApp.fetch(ENDPOINT, {
      method: 'post',
      contentType: 'application/json',
      headers: { 'x-import-secret': SECRET },
      payload: JSON.stringify({ answers: answers }),
      muteHttpExceptions: true,
    });
    const json = JSON.parse(res.getContentText());
    status = json.status || 'error';
    message = json.message || '';
  } catch (err) {
    message = String(err);
  }

  // 結果（登録 / 満員 / 重複 など）を、その回答の行の右端に書く
  sheet.getRange(row, resultColumn_(sheet)).setValue(statusLabel_(status) + (message ? '：' + message : ''));

  // 登録できなかった人には、メールで知らせる
  if (status !== 'accepted' && mail) {
    MailApp.sendEmail(
      mail,
      '【バレーボール大会】エントリーについてのお知らせ',
      'エントリーを受け付けられませんでした。\n\n理由: ' + message +
        '\n\n内容を確認して、もう一度申し込むか、運営にご連絡ください。'
    );
  }
}

function resultColumn_(sheet) {
  const lastCol = sheet.getLastColumn();
  const headers = sheet.getRange(1, 1, 1, lastCol).getValues()[0];
  const idx = headers.indexOf(RESULT_HEADER);
  if (idx >= 0) return idx + 1;
  sheet.getRange(1, lastCol + 1).setValue(RESULT_HEADER);
  return lastCol + 1;
}

function statusLabel_(s) {
  return { accepted: '登録済み', full: '満員', duplicate: '重複', invalid: '入力不正', error: 'エラー' }[s] || s;
}
```

### 動作確認
1. フォームに自分でテスト回答を送ります。
2. スプレッドシートの右端の「アプリ反映」列に「登録済み」と出て、アプリの人数が増えれば成功です。
3. テスト分は、運営モードの「削除」ボタン（チーム）や「取消」ボタン（当日チーム分け）で消せます。

## 3. アプリ側の設定

運営モードで「エントリー」ページを開き、「Googleフォーム連携」で次を設定します。

1. 受付方法を **「Googleフォームで受付」** にします（アプリ内のエントリーフォームが閉じます）。
2. 2つのフォームのリンク（「送信」→ リンクのアイコン）を貼り付けて、「リンクを保存」します。参加者のエントリー画面に、ボタンで表示されます。

## 困ったとき

- **「アプリ反映」列に「エラー」と出る**: `SECRET` が Vercel の `IMPORT_SECRET` と違う、または Vercel に未設定です。
- **「満員」と出る**: チーム15 / 当日チーム分け30人の上限に達しています。
- **「重複」と出る**: 同じチーム名・同じ名前が既に登録されています（同じ回答を二重に取り込んでも、二重登録にはなりません）。
- **自動反映が止まった**: スプレッドシートを、1行目（質問名）から全部コピーして、運営画面の「スプレッドシートから取り込む（手動）」に貼り付けてください。
